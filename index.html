FORMAÇÃO PROFISSIONAL

Informática para Internet e

Desenvolvimento de Sistemas

O curso integrado ou subsequente capacita os alunos a dominarem tecnologias essenciais do mercado de desenvolvimento web, da lógica inicial até arquiteturas de nuvem.

EIXO TECNOLÓGICO: INFORMAÇÃO E COMUNICAÇÃO

Etec Darcy Pereira de Moraes (Centro Paula Souza)

Informática para Internet

Curso técnico voltado à criação de sites, sistemas web e aplicações completas, unindo front-end, back-end e boas práticas de programação usadas no mercado de tecnologia.

  • Lógica de Programação e Algoritmos
  • Banco de Dados e Modelagem de Sistemas
  • Desenvolvimento Web Front-End e Back-End

Desenvolvimento de Sistemas

Curso técnico focado na construção de sistemas e aplicações robustas, abrangendo programação orientada a objetos, banco de dados e integração com tecnologias web.

  • Programação Orientada a Objetos
  • APIs, Servidores e Consumo de Dados
  • Projetos Práticos Integrando Web e Sistemas
